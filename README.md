# Page Replacement Algorithms Simulator

## Project Title

Implementation and Simulation of Page Replacement
Algorithms (FIFO, LRU, and Optimal) in C on Ubuntu.

## Description

This project implements and simulates three page
replacement algorithms:

- FIFO (First-In, First-Out)
- LRU (Least Recently Used)
- Optimal Page Replacement

The program simulates memory page replacement and
compares the performance of these algorithms.

## Development Environment

- Operating System: Ubuntu Linux
- Programming Language: C
- Compiler: GCC
- Version Control: Git
- Repository: GitHub
